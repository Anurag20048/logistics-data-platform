# Project Metadata

## Project
Logistics Data Platform v2

## Positioning
End-to-end Data Engineering project demonstrating:
- real-time streaming
- lakehouse-style storage
- data quality
- orchestration
- warehouse modeling
- analytical marts

## Stack
Kafka, Spark Structured Streaming, MinIO, PostgreSQL, Airflow, dbt, Docker, Pytest

## Data
- 1,000 customers
- 50,000 logistics events
- synthetic and reproducible with random seed 42

## Analytical outputs
- Customer Logistics 360
- Shipment Performance
- Delay rate
- Delivery rate
- Distance and shipment volume
- Truck utilization indicators

## Resume-ready description
Built an end-to-end logistics data platform using Kafka, Spark Structured Streaming, MinIO, PostgreSQL, Airflow and dbt, implementing event-time processing, deduplication, lakehouse-style storage, automated data-quality gates and tested analytical marts.
